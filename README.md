# Lyre desktop downloads

Official Lyre desktop installers and release notes.

## Downloads

- **Windows:** find published installers in [Releases](https://github.com/ClarionAI/lyre-releases/releases).
- **macOS:** coming soon.

Download the Windows installer from a release's Assets list. If no release is listed, the first installer has not been published yet.
